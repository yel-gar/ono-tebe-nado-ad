# Оно тебе надо

Проектная работа «Оно тебе надо» — страница аукциона вещей, в которые никто не верил. Статическая вёрстка на HTML и CSS.

## Структура

- `index.html` — разметка страницы;
- `styles/global.css` — глобальные стили;
- `styles/style.css` — стили проекта;
- `fonts/fonts.css` — подключение шрифтов Raleway;
- `images/` — изображения проекта.

## Запуск

Откройте `index.html` в браузере напрямую или запустите локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

После этого страница будет доступна по адресу <http://localhost:8000>.
